# zx — ИИ-агент на бесплатных моделях

Веб-приложение-чат в оформлении claude.ai, которое отвечает через **бесплатные тарифы**
десятков LLM-провайдеров — идея навеяна [FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi)
(«7.4 млрд токенов в месяц, 34 бесплатных провайдера, один `/v1` endpoint»).

Здесь та же идея, но проще и без установки их сервера: лёгкий агрегатор на клиенте + прокси.

## Что умеет

- **Авто-режим** — строит цепочку провайдеров по качеству
  (Google AI Studio → Groq → Cerebras → Mistral → OpenRouter `:free` → NVIDIA NIM → OVHcloud)
  и **автоматически переключается** при лимитах и ошибках: `429` у одного — отвечает следующий.
- **Стриминг** ответов, markdown, блоки кода с копированием, «размышления» reasoning-моделей (DeepSeek-R1-подобные) сворачиваются.
- **Выбор модели** из живого списка каждого провайдера (тянется по `/v1/models` и кэшируется).
- **Свой endpoint** — любой OpenAI-совместимый релей (как в freellmapi): URL + ключ + модель.
- История чатов в localStorage, переименование не нужно — заголовок берётся из первого сообщения.
- Ключи **не покидают браузер** (localStorage) и уходят напрямую провайдеру; сервер используется
  только как резервный прокси, если провайдер блокирует запросы из браузера (CORS).

## Быстрый старт

```bash
npm start          # или: node server.js
# → http://localhost:3000
```

Node.js ≥ 18. Зависимостей нет — один файл сервера и статика.

## Как получить ключи (всё бесплатно, карта не нужна)

| Провайдер | Ключ | Что даёт |
| --- | --- | --- |
| [Google AI Studio](https://aistudio.google.com/apikey) | по Google-аккаунту | свежие Gemini Flash, контекст до 1M |
| [Groq](https://console.groq.com/keys) | по аккаунту | самые быстрые GPT-OSS / Llama / Qwen / Kimi |
| [Cerebras](https://cloud.cerebras.ai) | по аккаунту | очень быстрый стриминг |
| [Mistral](https://console.mistral.ai/api-keys) | по аккаунту | Mistral Small/Medium, Codestral |
| [OpenRouter](https://openrouter.ai/settings/keys) | по аккаунту | сотни моделей с суффиксом `:free` |
| [NVIDIA NIM](https://build.nvidia.com/explore/discover) | по аккаунту | DeepSeek, Llama, Qwen на GPU NVIDIA |
| [OVHcloud AI Endpoints](https://endpoints.kepler.ai.cloud.ovh.net) | **ключ не нужен** | Qwen и другие открытые модели — работает сразу |

Достаточно одного ключа (рекомендуем начать с Google AI Studio). OVHcloud работает без ключа сразу.

## Как это работает

```
браузер (app.js)
  ├─ прямой запрос к провайдеру  ──✗ CORS? ──▶ /api/proxy (server.js) ──▶ провайдер
  └─ авто-цепочка: [Google, Groq, Cerebras, …] — перебор до первого успешного стрима
```

- `GET /api/providers` — каталог провайдеров (единый источник — `lib/providers.js`).
- `POST /api/proxy` — резервный прокси-стрим до `https://`-endpoint'ов; сервер не хранит ключи.
- Дневные лимиты бесплатных тарифов считаются на стороне провайдеров — фейловер просто
  переходит к следующему, когда у предыдущего кончился лимит.

> Примечание: GitHub Models, о котором часто пишут в подборках «бесплатных токенов»,
> закрыт 30 июля 2026 — поэтому агрегатор собран на живых бесплатных тарифах выше.

## Структура

```
server.js            — HTTP-сервер без зависимостей (статика + /api/proxy)
lib/providers.js     — каталог бесплатных провайдеров
public/index.html    — разметка (вёрстка в духе claude.ai)
public/style.css     — кремовая палитра, терракотовый акцент
public/app.js        — цепочки провайдеров, стриминг, чаты, настройки
public/vendor/       — marked + DOMPurify (локально)
test/                — мок-провайдер и интеграционный тест прокси/стрима
```
