# zx — ИИ-агент на бесплатных моделях

Веб-приложение в оформлении claude.ai: **агент для кода**, который выполняет команды в
терминале, читает и пишет файлы, и отвечает через **бесплатные тарифы** LLM-провайдеров
(идея навеяна [FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi) — «7.4 млрд
токенов в месяц, 34 бесплатных провайдера»). Плюс топовые **Claude Opus** и **GPT**
по вашему собственному ключу. Собирается в один файл **`zx-agent.exe`**.

## Что умеет

- **Режим агента** (включён по умолчанию, гаечный ключ у поля ввода):
  - инструменты `run_terminal`, `read_file`, `write_file`, `list_dir`, `web_search`, `web_fetch`;
  - модель сама смотрит файлы, правит их, запускает тесты/сборку и разбирает ошибки;
  - **каждое действие подтверждается в UI** (или галочка «не спрашивать в этой сессии»);
  - карточки действий прямо в чате: команда, вывод, код выхода, результаты поиска и текст страниц.
- **Поиск в интернете без ключей** — `web_search` (DuckDuckGo) и `web_fetch`
  (чтение страниц чистым текстом). См. [«Поиск в интернете»](#поиск-в-интернете).
- **Авто-режим моделей** — цепочка бесплатных провайдеров
  (Google AI Studio → Groq → Cerebras → Mistral → OpenRouter `:free` → NVIDIA NIM → OVHcloud)
  с авто-фейловером при лимитах и ошибках.
- **Топ-модели по вашему ключу**: Claude (Opus 5.x) через OpenAI-совместимый слой Anthropic
  и ChatGPT (GPT-5.x) через OpenAI API. Это платные API вендоров — явный выбор в меню моделей,
  в «Авто» они не подставляются.
- Стриминг, markdown, копирование кода, «размышления» reasoning-моделей, история чатов.
- **Свой endpoint** — любой OpenAI-совместимый релей (как в freellmapi).
- Ключи **не покидают браузер** (localStorage); сервер — только раздача UI, резервный прокси
  от CORS и исполнитель команд агента на вашей машине.

## Поиск в интернете

Агент умеет смотреть в интернете — **бесплатно, без ключей и регистрации**:

- **`web_search`** — поиск через HTML-версию **DuckDuckGo** (`html.duckduckgo.com`).
  Возвращает заголовки, ссылки и сниппеты; `limit` — сколько результатов (по умолчанию 6).
- **`web_fetch`** — открыть страницу из выдачи и прочитать её **чистым текстом**:
  HTML вычищается (скрипты, стили, навигация), HTML-сущности декодируются,
  JSON отдаётся как есть. Ограничения: 20 сек и ~2 МБ на скачивание; чтение
  кусками до 48К символов через `offset`/`length` — как у `read_file`.

Поиск выполняется **на машине пользователя** (в сеть ходит локальный сервер агента),
поэтому в собранном `zx-agent.exe` он работает так же, как из исходников. Ключи не нужны —
это обычные страницы DuckDuckGo.

> **В ограниченных сетях поиск может не работать**: корпоративный прокси, файрвол,
> блокировка DuckDuckGo или песочница CI без внешнего интернета — `web_search` вернёт
> ошибку, а остальные инструменты (терминал, файлы) продолжат работать. Именно поэтому
> интеграционные тесты проекта не ходят в реальный интернет — они проверяют только
> SSRF-защиту и отклонение недопустимых схем.

**Безопасность (SSRF).** `web_search` и `web_fetch` не ходят на локальные и приватные
адреса: `localhost`, `127.0.0.0/8`, `10.x`, `172.16–31.x`, `192.168.x`, `169.254.x`
(включая cloud-metadata), `::1`, `.internal` и подобные. Разрешены только `http`/`https`,
редиректы проверяются на каждом шаге. Иначе инструмент возвращает `{ ok: false, error }`.

## Запуск .exe (Windows)

Скачайте `zx-agent.exe` со страницы [Releases](../../releases) и просто дважды кликните:
откроется консоль сервера и браузер с приложением. Рабочая папка агента — папка,
из которой запущен exe. Остановка — Ctrl+C или закрыть консоль.

Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее → Выполнить в любом случае».

Пересобрать exe самостоятельно: `npm run build:exe` (нужен Node 22; сборка через
[@yao-pkg/pkg](https://github.com/yao-pkg/pkg), идёт и на CI — `.github/workflows/build-exe.yml`).

## Файлы любых размеров

- **＋ у поля ввода** или **перетащите файлы в поле** — вложения любого размера и сколько угодно.
- Загрузка идёт **чанками по 4 МБ** напрямую в папку проекта: `<рабочая папка>/zx-files/`.
- Мелкие текстовые файлы (до 200 КБ) автоматически **вшиваются в контекст** сообщения — модель видит их сразу.
- Крупные файлы агент читает сам, **кусками** (`read_file` с offset) — можно прицепить многогигабайтные логи и датасеты.

## «Бесконечные токены» — как это на самом деле

У облачных провайдеров дневные лимиты ставит сам провайдер — обойти их нельзя. Поэтому zx выжимает из бесплатного максимум:

- **Ротация с памятью лимитов**: когда у провайдера кончается дневная квота — он пропускается автоматически до полуночи, а запрос уходит следующему. Суммарно за день доступно все бесплатные квоты всех провайдеров сразу.
- **Сжатие контекста**: в больших проектах старые сообщения автоматически сокращаются — свежий контекст всегда помещается в лимиты бесплатных моделей.
- **Локальные модели — настоящий «∞»**: встроены Ollama и LM Studio. Установите [Ollama](https://ollama.com) (`ollama pull qwen3`) или [LM Studio](https://lmstudio.ai) — они появятся в меню автоматически, без ключей и без всяких лимитов: токены ограничены только вашим железом. В «Авто» они включаются последними — когда облачные квоты исчерпаны.

## Быстрый старт (из исходников)

```bash
npm install
npm test           # интеграционные + браузерные смоук-тесты
npm start          # → http://localhost:3000
```

Node.js ≥ 18. Рантайм-зависимостей нет (jsdom и pkg — только для тестов и сборки).

## API сервера

- `GET /api/providers` — каталог провайдеров (`lib/providers.js`)
- `GET /api/agent/info` — рабочая папка и платформа агента
- `POST /api/tools/exec` — исполнение инструментов агента (`run_terminal`, `read_file`, `write_file`, `list_dir`, `web_search`, `web_fetch`)
- `POST /api/proxy` — резервный стрим-прокси (CORS), ключи не хранит

Переменные окружения: `PORT`, `HOST`, `ZX_WORKSPACE` (рабочая папка агента), `ZX_NO_OPEN=1` (не открывать браузер).

> Примечание: GitHub Models из старых подборок «бесплатных токенов» закрыт 30.07.2026 —
> поэтому агрегатор собран на живых бесплатных тарифах выше.

## Структура

```
server.js            — HTTP-сервер без зависимостей (статика, прокси, инструменты агента)
lib/providers.js     — каталог провайдеров (бесплатные + топовые по ключу)
public/index.html    — разметка (вёрстка в духе claude.ai)
public/style.css     — кремовая палитра, терракотовый акцент
public/app.js        — агентский цикл, цепочки провайдеров, стриминг, чаты
public/vendor/       — marked + DOMPurify (локально)
test/                — интеграционные тесты и браузерный смоук (jsdom)
.github/workflows/   — сборка zx-agent.exe на GitHub Actions
```
