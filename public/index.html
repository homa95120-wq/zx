zx бесплатный агент

Доброе утро

Агент для кода: выполняет команды в терминале, читает и пишет файлы,
отвечает через бесплатные модели (Gemini, GPT-OSS, DeepSeek, Qwen) —
или через топовые Claude и GPT по вашему ключу.

Бесплатные тарифы провайдеров · лимиты запросов в день · ключи хранятся только в вашем браузере

Настройки

Провайдеры и ключи

Бесплатные ключи — без карты. Claude и GPT — платные API вендоров по вашему ключу. Всё хранится только в этом браузере.

Свой endpoint (OpenAI-совместимый)

Любой другой бесплатный релей — как в freellmapi: укажите URL, ключ и модель.

Инструкции для агента

Системный промпт — добавляется к каждому чату.

Ничего не отправляется на наш сервер — только выбранному провайдеру.

Разрешить действие?

Агент просит выполнить действие на вашем компьютере. Проверьте его внимательно.


      
    

    

      Действие выполнится локально в рабочей папке агента.
      
      
    

  






  

    

      
Рабочая папка агента

      
    

    

      
Здесь агент выполняет команды, читает и пишет файлы. Здесь же хранятся вся история чатов и контекст — файлом zx-context.json.

      
Сейчас: 

      
      
      
Выбор запоминается и действует при следующих запусках. Ключи моделей при смене папки не переносятся — они остаются в этом браузере.

    

    

      Сменить папку можно в любой момент — контекст подгрузится из неё.
